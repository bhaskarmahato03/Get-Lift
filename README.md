# LiftLink 🚗

**A location-based lift-sharing platform that connects lift providers with people looking for a ride.**

## About

LiftLink is a web-based lift-sharing platform designed to connect people traveling in similar directions. Vehicle owners or drivers can share their available seats, while people looking for transportation can discover and request suitable lifts.

## Features

- Separate accounts for lift providers and lift seekers
- Secure user authentication
- Vehicle registration and provider verification
- Trip creation and ride requests
- Location-based trip search
- Maps and route visualization
- Ride ratings and reviews
- Admin dashboard and safety features

## Tech Stack

**Frontend:** React.js, Tailwind CSS  
**Backend:** Python, FastAPI  
**Database:** MongoDB  
**Authentication:** JWT  
**Maps:** Leaflet, OpenStreetMap  
**Additional Services:** Firebase, Cloudinary (planned)

## Project Structure

- `frontend/` — React frontend
- `backend/` — FastAPI backend
- `docs/` — Project documentation
